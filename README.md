MDInternational Website

This repository contains the official website of our organization. The website provides information about our mission, activities, charitable projects, and ways for visitors to get involved.

About the Website
The website was developed to create an accessible online platform where visitors can learn more about our organization, stay informed about upcoming activities, and discover the projects we support.

Features
Home: Introduction to the organization and its mission.
About Us: Information about the organization and its board members.
Agenda: An overview of upcoming events and activities.
Blog: News, updates, and information about our projects.
Contact: Contact information and a form for visitors to get in touch.
Donations: Information about how visitors can support our charitable initiatives.

Technologies Used
The website was built using:
HTML5
CSS3
The website uses a static structure without a dedicated backend.

Hosting
The website is hosted using GitHub Pages, allowing it to be publicly accessible online.

Maintenance
The website is regularly updated with new blog posts, upcoming events, and information about ongoing projects.

Purpose
Our goal is to raise awareness, encourage community involvement, and provide support to people in need through our charitable initiatives.
